# 🎬 Nitya VFX Studio — Production Management System

**Built with Streamlit + SQLite**

---

## ▶️ Run Locally

```bash
pip install streamlit pandas
streamlit run app.py
```
Open: http://localhost:8501

---

## 🌍 Deploy FREE on Streamlit Cloud

1. Create account at **share.streamlit.io**
2. Push this folder to a **GitHub repo**
3. On Streamlit Cloud → **New app** → select your repo → `app.py`
4. Click **Deploy** — live in 2 minutes!

> ⚠️ Streamlit Cloud resets the SQLite file on each redeploy.
> For permanent data, use a free **Supabase** or **PlanetScale** DB (contact us to upgrade).
> For a small team (< 20 people), the local database works fine when run on your own computer.
