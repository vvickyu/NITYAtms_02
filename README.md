## ▶️ Run Locally

```bash
pip install streamlit
streamlit run app.py
```
Open: http://localhost:8501

---

## 🌍 Deploy on Streamlit Cloud (Free)

1. Go to **[github.com](https://github.com)** → create a new repo → `nityavfx`
2. Upload all 4 files: `app.py`, `portal.html`, `requirements.txt`, `README.md`
3. Go to **[share.streamlit.io](https://share.streamlit.io)** → New app
4. Select your repo → main file: `app.py` → **Deploy**
5. Live in ~2 minutes at `yourname-nityavfx.streamlit.app` ✅

---

## 💾 How Data is Saved

Data is saved in your **browser's localStorage** automatically after every change.

- ✅ Works on any device with a browser
- ✅ Survives page refresh
- ✅ Auto-saves within 400ms of any change
- ⚠️ Data is per-browser (clearing browser data removes it)
- ⚠️ Different devices don't share data automatically

**For shared team data across devices:** use the Export/Import JSON feature in the portal (top nav) to transfer data between devices.
